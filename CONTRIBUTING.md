# Contribuir

Abre un issue describiendo el problema, sistema operativo, versión de Node y pasos de reproducción. Para cambios, utiliza una rama y un pull request con qué cambia y cómo lo comprobaste.

```bash
npm ci
npm run check
npm test
npm run diagrams -- projects/avatar-pipeline
```

No hace falta generar vídeos de pago para contribuir. Añade pruebas con respuestas simuladas cuando cambies el contrato de un proveedor. No incluyas claves, vídeos personales ni binarios de terceros. Conserva los guiones en español y documenta cambios en variables y comandos.
